# YouTube-промо: инструкция

Набор скриптов для массового редактирования описаний СВОИХ видео на YouTube:
- **`yt_promo.py`** — дописывает в конец описаний промо-блок с 2 ссылками (ratescout.ru + magzgold.ru).
- **`yt_cleanlinks.py`** — вырезает из описаний ВСЕ ссылки, кроме проектных (ratescout.ru/magzgold.ru). Текст не трогает.
- `promo.txt` — текст промо-блока (правится под себя).

Оба скрипта: идемпотентны (повторный запуск не дублирует), есть `--dry-run` (показать без изменений),
безопасны по квоте (обрабатывают порцию в день, остальное — при следующих запусках).
`yt_cleanlinks.py` дополнительно делает бэкап описаний и умеет откат.

## Подготовка (разово, ~5–10 минут)

### 0. Python
Нужен Python 3.9+. Проверка: `python --version`. Если нет — поставь с python.org (на Windows отметь «Add Python to PATH»).

### 1. Проект Google Cloud + включить API
1. **console.cloud.google.com** → войди Google-аккаунтом канала.
2. Селектор проектов (вверху) → **New Project** → создай, выбери его.
3. ☰ → **APIs & Services → Library** → найди **YouTube Data API v3** → **Enable**.

### 2. Экран согласия (Google Auth Platform)
1. ☰ → **APIs & Services → OAuth consent screen**.
2. Если есть кнопка **Get started** — нажми, заполни App name + email, на шаге **Audience** выбери **External**, дальше Contact → Create.
3. Открой вкладку **Audience** → статус должен быть **Testing** (если «In production» — нажми **Back to testing**).
4. В разделе **Test users** → **Add users** → впиши **свой Gmail** → Save.

### 3. Ключ (OAuth client)
1. Вкладка **Clients** (или ☰ → APIs & Services → Credentials) → **Create client** / **+ Create credentials → OAuth client ID**.
2. Application type: **Desktop app** → Create → **Download JSON**.
3. Переименуй в **`client_secret.json`**, положи в эту же папку (рядом со скриптами).

### 4. Библиотеки (разово)
Открой терминал в этой папке (в проводнике набери `cmd` в адресной строке) и выполни:
```
pip install google-api-python-client google-auth-oauthlib
```
(если `pip` не найден: `python -m pip install google-api-python-client google-auth-oauthlib`)

## Запуск

### Добавить промо-ссылки в конец описаний
```
python yt_promo.py --dry-run     # показать, что будет
python yt_promo.py               # применить
```

### Оставить в описаниях только проектные ссылки (вырезать чужие)
```
python yt_cleanlinks.py --dry-run
python yt_cleanlinks.py
python yt_cleanlinks.py --restore   # откат из descriptions_backup.json
```

При первом запуске откроется браузер → выбери аккаунт → «Google hasn't verified this app» →
**Advanced → Go to … (unsafe) → Continue → Allow** (для тест-юзера всегда доступно).

## Квота (важно)
YouTube API даёт 10 000 единиц/день, одно изменение видео = 50 → **~190 видео в день**.
Когда лимит кончится, скрипт напишет «квота исчерпана» и выйдет — **это нормально**.
Просто запусти команду **снова на следующий день**: обработанные видео пропустятся, допишет/дочистит остаток.
Для ~436 видео это 2–3 дня.

## Файлы, которые появятся рядом
- `token.json` — сохранённый вход (второй раз браузер не нужен). Не публиковать.
- `descriptions_backup.json` — бэкап оригинальных описаний (для `--restore`). Не публиковать.

## Заметка про SEO
Ссылки в описаниях YouTube — **nofollow**: это трафик/охват, не рост позиций сайтов. Метки `utm_source=youtube`
позволят видеть переходы в Яндекс.Метрике/Google Analytics.
